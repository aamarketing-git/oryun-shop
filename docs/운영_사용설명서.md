# 오륜쇼핑몰 운영 사용설명서

> 내 사이트 주소: `https://oryun-shop-mwx6.vercel.app`
> (Vercel에서 발급된 본인 주소로 읽으세요)

이 문서는 사이트가 배포된 후, 실제로 운영을 시작하는 방법을 단계별로 정리한 것입니다.
순서대로 따라 하시면 됩니다.

---

## 0단계. 가장 먼저 — 관리자 계정 만들기 (필수, 1회만)

지금 사이트는 상품도 사용자도 없는 빈 상태입니다. 모든 운영은 **관리자 계정**에서 시작합니다.

### ① 회원가입
1. 사이트 접속 → 우상단 햄버거(☰) → **로그인 / 회원가입**
2. 또는 주소 직접 입력: `내사이트주소/auth/register`
3. **개인 구매자**로 가입 (이메일·비밀번호·이름·연락처)
4. 가입한 이메일·비밀번호 기억해두기

### ② 관리자로 승격 (Supabase에서)
1. Supabase 대시보드 → 좌측 **SQL Editor** → **New query**
2. 아래 입력 (이메일은 ①에서 가입한 본인 이메일로 바꾸기):
   ```sql
   UPDATE profiles SET role = 'admin' WHERE email = '본인이메일@example.com';
   ```
3. **Run** → `Success` 확인

### ③ 관리자 로그인
1. 사이트에서 **로그아웃** 후 다시 **로그인**
2. 이제 관리자 권한이 적용됨 → `내사이트주소/admin/dashboard` 접속
3. 관리자 대시보드가 보이면 성공

> 💡 관리자는 보통 1명이면 됩니다. 추가 관리자가 필요하면 같은 방법으로 승격하세요.

## 1단계. 카테고리 만들기 (관리자)

상품을 등록하려면 먼저 카테고리가 있어야 합니다. 기본 카테고리(디지털/스테이킹/라이프/액세서리)는 설치 시 자동 생성됩니다(`004_seed.sql`).

확인 방법: Supabase → **Table Editor** → `categories` 테이블에 4개 행이 있는지 확인.
없으면 SQL Editor에서 아래 실행:
```sql
insert into categories (name, slug) values
  ('디지털','digital'), ('스테이킹','staking'),
  ('라이프스타일','lifestyle'), ('액세서리','accessories');
```

## 2단계. 공급자(판매자) 등록 및 승인

상품은 **공급자**가 등록합니다. 공급자는 가입 → 관리자 승인 후 활동 가능합니다.

### 공급자 입장 — 가입 신청
1. `내사이트주소/auth/register` 접속
2. 가입 화면에서 **공급자** 선택
3. 정보 입력:
   - 상호명, 대표자명, 사업자등록번호
   - 연락처
   - 정산 계좌 (은행/계좌번호/예금주)
   - USDT 지갑 주소 (TRC20)
   - 사업자등록증 업로드 (선택)
   - 고객 문의 채널 (카카오톡/전화/텔레그램)
4. **승인 신청 제출** → "승인 대기" 상태가 됨

### 관리자 입장 — 공급자 승인
1. 관리자로 로그인 → `내사이트주소/admin/sellers`
2. **대기(Pending)** 탭에서 신청한 공급자 확인
3. 사업자등록증 등 검토
4. **승인** 클릭 → 공급자가 상품 등록 가능해짐
   - 문제 있으면 **거절**

> 본인이 직접 판매도 할 거라면: 별도 이메일로 공급자 가입 → 관리자 계정으로 승인하면 됩니다.

---

## 3단계. 상품 등록 (공급자 → 관리자 승인)

상품은 2단계로 노출됩니다: **공급자가 등록** → **관리자가 상세페이지 작성 후 승인**.

### 공급자 입장 — 상품 등록
1. 공급자로 로그인 → `내사이트주소/seller/products`
2. **새 상품** 클릭 (`/seller/products/new`)
3. 입력:
   - 상품명, 카테고리, 판매가(원)
   - 재고
   - 짧은 설명 (목록 카드용)
   - 대표 이미지 (권장 1200×1200 정사각형)
   - 배송 방식: 택배 / 직접 전달(디지털)
4. **제출** → "승인 대기" 상태

> ⚠️ 공급자는 상세페이지(Hero/Feature/Spec)를 만들 수 없습니다. 디자인 통일성을 위해 관리자만 작성합니다.

### 관리자 입장 — 상세페이지 작성 + 승인
1. 관리자 로그인 → `내사이트주소/admin/products`
2. **승인 대기** 탭에서 해당 상품 클릭 → **에디터** (`/admin/products/[id]/detail`)
3. 허용된 5가지 섹션으로 상세페이지 구성:
   - **Hero** (대표 타이틀/이미지)
   - **Feature** (특징 3개)
   - **Spec** (사양 표)
   - **Gallery** (이미지 갤러리)
   - **Callout** (강조 문구)
4. **저장 후 승인** → 상품이 사이트에 노출됨

> ⚠️ **상세페이지를 작성하지 않으면 승인되지 않습니다.** (디자인 깨짐 방지 장치)

### 확인
사이트 홈(`내사이트주소/`)을 새로고침하면 승인된 상품이 그리드에 나타납니다.

## 4단계. 주문 흐름 (소비자)

소비자가 상품을 구매하는 과정입니다.

1. 홈 또는 상품목록(`/products`)에서 상품 선택
2. 상품 상세 → **바로 구매하기**
3. 체크아웃(`/checkout`)에서:
   - 배송 정보 입력
   - **스테이킹 지갑 주소 입력** (필수 — 미입력 시 주문 불가)
   - 결제 방법 선택: **계좌이체** 또는 **USDT**
4. 주문 생성 → 결제 진행

### 계좌이체 결제
- 공급자 입금 계좌가 표시됨 → 소비자가 입금
- 공급자가 입금 확인 → 주문 상태 "결제 확인"으로 변경

### USDT 결제
- 송금 주소 + QR코드 + 변환 금액(USDT) 표시
- 소비자가 송금 후 **TXID(트랜잭션 해시)** 입력
- 관리자/공급자가 TXID 검증 → "결제 확인"
- ⚠️ 동일 TXID 재사용 불가 (중복 방지)

---

## 5단계. 주문 처리 (공급자)

1. 공급자 로그인 → `내사이트주소/seller/orders`
2. 새 주문 확인 → 주문 상세 클릭
3. 결제 확인 (계좌이체는 입금 확인, USDT는 TXID 확인)
4. **결제 확정** → 배송 단계로
5. **배송 등록**:
   - 택배: 택배사 + 송장번호 입력
   - 직접 전달: 이메일/링크 등
6. 상태 변화: 결제대기 → 결제확인 → 배송준비 → 배송중 → 배송완료

## 7단계. 환율 설정 (관리자)

USDT 결제 금액 계산에 쓰이는 환율입니다.
1. `내사이트주소/admin/settings/rate`
2. 현재 환율 확인 (기본 1 USDT = 1,500원)
3. 새 환율 입력 → **업데이트**
4. 변경 후 생성되는 주문부터 적용 (진행 중 주문은 기존 환율 유지)

## 자주 묻는 운영 질문

**Q. 상품을 올렸는데 사이트에 안 보여요.**
→ 관리자가 상세페이지를 작성하고 **승인**해야 노출됩니다. `/admin/products`의 승인 대기 탭 확인.

**Q. 공급자가 로그인했는데 상품 등록이 안 돼요.**
→ 관리자 승인 전입니다. `/admin/sellers`에서 승인하세요.

**Q. 이미지를 올렸는데 안 보여요.**
→ Supabase Storage의 `products` 버킷이 **Public**인지 확인하세요.

**Q. USDT 받을 지갑을 바꾸고 싶어요.**
→ Vercel → 프로젝트 → Settings → Environment Variables에서 `USDT_RECEIVE_ADDRESS_TRC20` / `ERC20` 수정 후 재배포.

**Q. 환경변수를 바꿨는데 반영이 안 돼요.**
→ Vercel에서 환경변수 변경 후 **Redeploy**(재배포)해야 적용됩니다.

**Q. 도메인을 내 것으로 바꾸고 싶어요.**
→ Vercel → 프로젝트 → Settings → Domains에서 보유 도메인 연결 가능.
